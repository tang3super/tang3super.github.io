信号筛选规则说明

这不是"深度虚值期权清单"，而是从可配置的标的池里，同时满足5个条件才会被记录下来的异常放量信号。

维度规则
标的范围可配置，当前配置为：SNDK / NVDA / GLW / VRT / TSM / SKHY / TSLA / CRDO / MRVL / MU / GOOG / MSFT / AMZN / META / AAPL / QCOM / NVTS
到期窗口未来7天内到期的合约
虚值程度虚值 ≥ 15% 才算"深度虚值"
成交量单合约成交量 ≥ 500张，且是昨日成交量的 ≥ 5倍（此前无成交记录的合约，视为首次放量直接计入）
权利金单笔信号权利金 ≥ 5万美元
5个条件同时满足才会出现在信号里，任何一项不达标都会被静默过滤掉，不会展示——这也是"异动"这两个字的由来：不是把所有深度虚值合约列出来，而是专挑放量明显超出历史基线的那一小部分。

方向判定说明

成交价格相对买一/卖一报价的位置：成交价贴近或高于卖一价，判定为主动买入；贴近或低于买一价，判定为主动卖出。系统只保留判定为买入的信号。
